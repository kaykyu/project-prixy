# Prixy

#### Food and Beverage Point of Sale System
This project is designed for the food and beverage industry. Built using Angular for the frontend and Spring Boot for the backend, Prixy offers a robust and user-friendly platform to streamline your POS operations.

## Features

- User-Friendly Interface: Angular-based frontend providing an intuitive and responsive design for easy navigation and efficient use.
- Customized Menus: Create and manage your menus for different categories
- Order Management: Efficiently manage and process orders, track order status, and handle modifications and cancellations.
- Sales Reporting: Generate detailed sales reports and analytics to track performance and make informed business decisions.
- Secure Authentication: Spring Boot-based backend ensures secure user authentication and role-based access control.
- Real-Time Data Synchronization: Keep data synchronized across devices and users with real-time updates.
- Mobile Optimization: Optimized for mobile devices for customers, ensuring a seamless customer experience on smartphones and tablets.
